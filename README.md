# Yati Jaiswal — Data Analytics Portfolio

Interactive, responsive portfolio website built with **HTML, CSS and vanilla JavaScript** and designed for GitHub Pages.

## Included

- Responsive navigation
- Light / dark mode with localStorage
- Animated scroll progress
- Scroll reveal animations
- Animated statistics
- Searchable and filterable projects
- Interactive project case-study modal
- Skills section
- Experience / education timeline
- GitHub and LinkedIn links
- Mobile-friendly layout
- No framework or build step required

## Folder structure

```text
.
├── index.html
├── README.md
└── assets
    ├── css
    │   └── style.css
    ├── js
    │   ├── projects.js
    │   └── script.js
    ├── images
    │   └── README.txt
    └── Yati_Jaiswal_Resume.pdf   ← add your real resume here
```

## Before publishing

1. Replace `your-email@example.com` in `index.html` with your actual email.
2. Add your resume as `assets/Yati_Jaiswal_Resume.pdf`.
3. Add dashboard screenshots to `assets/images/` if you want visual previews.
4. Replace or add project links inside `assets/js/projects.js` as your GitHub / Tableau / Power BI links become available.
5. Check every project description so it exactly matches the work you personally completed.
6. Commit the files to your GitHub repository.
7. In GitHub: **Settings → Pages → Deploy from a branch → main → / (root)**.

## GitHub Pages

For a repository named `yatijaiswal435-collab.github.io`, the site can use the root `index.html`.

For a normal project repository, GitHub Pages can publish the root of the `main` branch.

## Important

This portfolio intentionally uses only vanilla HTML/CSS/JavaScript, so you do not need npm, React, Node.js or a build process to publish it.
